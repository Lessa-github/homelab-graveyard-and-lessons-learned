# 🪦 O Cemitério de Softwares & Tradeoffs Reais de Engenharia

> *"Engenharia sênior não é sobre o que você instala. É sobre o que você tem coragem de desinstalar depois de medir os dados reais."*

Este repositório reúne os estudos de caso, testes de carga e benchmarks que justificaram a **desinstalação ou descarte** de ferramentas populares que se mostraram ineficientes, pesadas ou inseguras para o nosso ambiente.
